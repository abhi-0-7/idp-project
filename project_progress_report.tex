\section{Work Completed to Date}

\subsection{Phase 1: Environment and Infrastructure Setup}
\begin{itemize}
    \item \textbf{Development Environment:} Established a Python 3.9+ virtual environment with all core dependencies including OpenCV, Torch, and Ultralytics.
    \item \textbf{Web Architecture:} Developed a Flask-based web server to host the project, enabling a move from CLI scripts to a professional dashboard interface.
    \item \textbf{Data Pipeline:} Successfully configured mobile IP Webcam integration for high-definition video and raw audio streaming via local network.
\end{itemize}

\subsection{Phase 2: Vision Module and Model Comparison}
\begin{itemize}
    \item \textbf{Asynchronous Architecture:} Implemented a multi-threaded system where video capture, inference, and UI streaming run in parallel. This ensures a consistent \textbf{30 FPS} video feed even when running heavy models.
    \item \textbf{Model Integration:} Integrated three distinct YOLO versions (YOLOv11 Nano, YOLOv10 Extra Large, and YOLOv11 Extra Large).
    \item \textbf{Performance Optimization:} Optimized CPU inference using image scaling (imgsz=320) to ensure real-time responsiveness.
    \item \textbf{Metrics Overlay:} Implemented real-time tracking of FPS, Inference Time (ms), and Person Count displayed directly on the dashboard.
\end{itemize}

\subsection{Phase 3: Audio Signal Processing}
\begin{itemize}
    \item \textbf{Live Stream Decoder:} Built a real-time decoder for the IP Webcam audio stream.
    \item \textbf{RMS Processing:} Implemented Root Mean Square (RMS) volume calculation to monitor sound intensity.
    \item \textbf{Sensitivity Tuning:} Applied a 5x gain factor to ensure accurate panic detection based on acoustic environments.
\end{itemize}

\section{Current Project Status}
The project has successfully moved from the initialization phase to a functional multi-sensor monitoring system. The core vision and audio engines are stable, and the web-based dashboard is fully operational.

\subsection{Phase 5: FPGA Integration via UART}
\textbf{Goal:} Establish physical hardware alerts.
\begin{itemize}
    \item \textbf{Task:} Implement Python-to-FPGA serial communication using PySerial.
    \item \textbf{Task:} Write Verilog/VHDL code for the FPGA to decode UART signals and trigger LEDs/Buzzers.
\end{itemize}
